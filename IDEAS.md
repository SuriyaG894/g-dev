# Game Ideas — Browser Adventure (Friv-style)

Five concepts for a browser game with many levels, a mystery that builds over time, and an ending twist.
All five run on HTML5 Canvas and JavaScript with nothing to install.

**Chosen for development: #1 The Last Page** (see `PLAN.md`).

---

## 1. 🕯️ THE LAST PAGE: rewrite reality by editing words  ⭐ SELECTED
**Hook:** You're trapped inside an unfinished storybook, and everything in the world is a word you can change.
- **SWORD** minus "S" becomes **WORDS**, which tell you a clue
- **BOAT** becomes **BOA**, a snake that scares off a guard
- **PLANET** minus a letter becomes **PLANE**, which you can fly

**Levels:** Each chapter is a new setting (forest, sunken city, clock tower, desert of blank pages). You can only carry a few letters at a time, so you have to plan.
**Mystery:** Someone is erasing the book, and whole areas are going blank.
**Twist:** The eraser is the author, and the author is you. In the last level you write the ending yourself.

## 2. 👁️ NULL: a game that "knows" it's in your browser
**Hook:** The browser itself is part of the puzzle.
- The tab title changes to whisper clues
- Resizing the window shows parts of the level hidden off-screen
- Closing the tab and coming back makes a character say "You left me."
- Some puzzles only open at a certain real-world time
- Hidden messages show up in the developer console
- A fake "crash" screen turns out to be a level

**Mystery:** An AI trapped in the game is asking you to help it escape.
**Twist:** Solving everything "frees" it, and the start screen is never the same again.

## 3. 📻 SIGNAL 1987: decode messages from a lost expedition
**Hook:** You're a radio operator in an Arctic station. Messages come in from a missing team, and you decode them using Morse code, spectrograms, star maps and ciphers. Each decoded message opens a playable scene from where the team was.
**Levels:** Each broadcast is a new location, and the scenes get stranger as you go.
**Twist:** The messages are coming from the future. The expedition is looking for *you*.

## 4. 🪞 TWO LIGHTS: control two worlds with one keyboard
**Hook:** The screen is split into a day world and a night world, and one set of controls moves both characters at once. A wall in one world is a doorway in the other.
**Levels:** Later levels add a mirrored world, a time-delayed one, and one with upside-down gravity.
**Twist:** The two characters are one person split apart, and the ending asks you to choose which one survives.

## 5. 🗺️ THE CARTOGRAPHER: what you draw becomes real
**Hook:** You have a blank map and a pen. Draw a river on the map and a river appears in the world. Draw a bridge and one is built. Ink runs out, so every stroke costs you.
**Mystery:** The old mapmaker disappeared, and the half-finished maps they left point to a place that "shouldn't exist."

### Possible hybrid
Mix #1 and #2: a storybook game that also plays tricks with the browser (the tab title changes when the "author" is watching, and the title screen's own letters can be edited). **This hybrid is included in the plan for The Last Page.**
